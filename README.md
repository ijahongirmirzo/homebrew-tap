# Homebrew tap

Homebrew casks by Jahongirmirzo.

```bash
brew install --cask ijahongirmirzo/tap/pulli
```

| Cask | App |
|---|---|
| `pulli` | [Pulli](https://github.com/ijahongirmirzo/pulli): copy photos and files from your Android phone to your Mac, and never lose progress |

Pulli updates itself; `brew upgrade` also works.
